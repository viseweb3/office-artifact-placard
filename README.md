A tiny deterministic program that writes a one-line museum placard for an ordinary stapler, treated as an ancient artifact, to `/output/entry.txt` for make.fun's "Office Artifacts: The One-Line Placard Contest" bounty. Entry by @oxcaleeev; GitHub owner viseweb3.

Bounty: https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2

## Run it

```sh
node main.ts
```

This writes the placard (170 characters, one line) to `/output/entry.txt`.
